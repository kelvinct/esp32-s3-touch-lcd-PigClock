基於 ESP32-S3-Touch-LCD-2 開發板嘅開源智能時鐘，結合同步時鐘、天氣顯示、動漫小豬遊戲、AI 互動元素於一身。由最初嘅基本時鐘，逐步演化成一個功能豐富嘅桌面小夥伴。

*核心定位
「唔止係時鐘，仲係一個會陪你過每一日嘅小豬夥伴」

🕐 實用性：報時 + 天氣 + 日期
🎮 娛樂性：小豬動畫 + 敵人遊戲 + 物理互動
 硬件規格
項目	規格
開發板	Waveshare ESP32-S3-Touch-LCD-2
主控	ESP32-S3R8 雙核 240MHz
記憶體	16MB Flash + 8MB PSRAM
螢幕	2" IPS 240×320 (ST7789T3)
觸控	電容 CST816D (I2C)
IMU	QMI8658 六軸 (陀螺儀+加速度計)
無線	2.4GHz WiFi + BT 5
開發環境	PlatformIO + Arduino Framework
